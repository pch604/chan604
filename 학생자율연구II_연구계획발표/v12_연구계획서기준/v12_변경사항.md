# v12 — 연구계획서(HWP) 기준으로 재정렬

v8~v11은 "측정 시간 맞추기(지연 처리)"를 연구의 중심처럼 다뤘습니다. 이는 연구계획서와 다릅니다. v12는 연구계획서의 주제, 목적, 방법, 평가를 그대로 따릅니다.

| 연구계획서 항목 | v12 슬라이드 |
|---|---|
| 주제: GPS 사용 불가 환경에서 비전 보조 항법을 위한 다중센서 융합 | 1 표지 (부제: 카메라·IMU 융합 기반 위치·속도·자세 추정과 영상 측정 품질 반영) |
| 필요성: IMU 누적 오차, 카메라의 조명·흐림·특징점 부족·깊이 불확실 | 2 배경, 3 필요성 (IMU vs 카메라 비교 그림) |
| 목적: filter 기반 상태추정 구현, 영상 측정 품질에 따른 성능 변화 분석, 정확성·안정성 평가 | 3 연구 목적 상자 |
| 이론적 배경: 예측·보정 filter, 옵티컬 플로우(병진·회전·깊이), 거리 스케일·평면 가정, 품질 지표 | 4 이론적 배경 (영상 이동 구성 그림) |
| 연구방법 ①~③: 전처리(GPS 입력 제외), MATLAB 기준 추정기, 영상 품질 반영(비중 축소·보정 생략) | 5 연구방법 (구조도, 품질 지표에 빨간 강조) |
| 연구방법 ④: IMU 단독 / 고정 신뢰도 / 영상 신뢰도 반영, 주행 조건, 흐림·프레임 누락, 위치 RMSE·최종 오차·중단 시 오차 증가·속도 RMSE·처리시간 | 6 실험 및 평가 계획 |
| 연구방법 ⑤ 및 일정 | 7 연구계획 |
| 참고문헌 [1]~[4] | 8 참고문헌 (계획서 4편 + 배경 인용 Groves, Bayard) |

- **시간 동기화·지연 보상:** 연구계획서대로 ① 전처리 항목과 연구실 선행연구 참고 범위로만 남겼습니다. 시간축 그림과 A/B/C 지연 처리 비교는 뺐습니다.
- **글꼴:** 모든 글자를 확인했습니다. 영문 Arial, 한글 MS PGothic이며 예외는 0건입니다.
- **글자 크기:** 17 / 15.5 / 14 / 12 / 10.5 pt 다섯 단계로 통일했습니다.
- **데이터셋:** 연구계획서에 특정 데이터셋이 없어 슬라이드에도 넣지 않았습니다. 정해지면 6번 실험 조건에 한 줄 추가하면 됩니다.
