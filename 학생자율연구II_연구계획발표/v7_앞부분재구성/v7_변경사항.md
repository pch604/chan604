# v7 변경 사항 — 앞부분(배경 · 필요성 · 목적) 재구성

v6과 달라진 것은 2번(연구 배경)과 3번(연구의 필요성 및 목적) 슬라이드, 그리고 참고문헌 2편 추가뿐입니다. 4번 이후의 선행연구, 연구방법, 구현·평가, 일정은 v6 그대로입니다.

## 형식: 보내주신 예시를 따름

- **연구 배경:**
  - 위쪽 회색 띠: `GPS 제한 환경 ··· IMU 오차 누적 ··· 비전 보조 항법의 중요성`
  - 왼쪽 선 아이콘, 오른쪽 ☆ 소제목과 문장(핵심어는 파란색, 끝에 인용)
- **필요성 및 목적:**
  - 큰 선 아이콘 3개 + 제목 + 파란 핵심어 + 짧은 설명 + 인용
  - 그 아래 "→ 세 센서 융합 / → 본 연구가 다룰 문제" 묶음선, 맨 아래 연구 목적 띠
- **표 형태 제거:** 박스로 칸을 나누던 구성을 없앴습니다.
- **아이콘:** Tabler Icons(MIT 라이선스)의 공개 선 아이콘만 썼습니다. AI가 그린 그림은 없습니다.

## 문장마다 붙은 근거

| 문장 | 근거 |
|---|---|
| GPS 제한 환경에서 관성 항법에 의존하고, 오차가 시간에 따라 누적 | Groves, *Principles of GNSS, Inertial, and Multisensor Integrated Navigation Systems*, 2nd ed., 2013 |
| 영상의 움직임을 IMU와 결합해 위치·자세 추정 | Mourikis and Roumeliotis, ICRA 2007 |
| 하향 카메라 + 거리센서로 Optical Flow 항법 | PX4 User Guide "Optical Flow": 하향 카메라와 하향 거리센서(LiDAR 권장)가 필요하다고 명시 |
| 화성 헬리콥터 Ingenuity가 하향 카메라·IMU·레이저 고도계 사용 | Bayard et al., AIAA SciTech 2019 |
| 영상 속 이동만으로는 실제 거리를 몰라 거리센서가 필요 | PX4 User Guide "Optical Flow" (위와 같음) |
| 타임스탬프와 실제 측정 시점의 차이가 성능을 저하 | Qin and Shen, IROS 2018 |
| PX4도 센서별 지연값을 따로 보정 (대본) | PX4 EKF2 파라미터 EKF2_OF_DELAY, EKF2_RNG_DELAY |

제가 임의로 만든 예시나 수치(예: 이전의 "5 m/s × 50 ms")는 넣지 않았습니다.

## 검수

- 4:3 비율, VDEC 배너, 제목과 밑줄 유지
- 모든 새 글자: 영문 Arial, 한글 MS PGothic
- 렌더링 확인: 글자 넘침·겹침 없음, 인용은 줄이 꺾이지 않도록 따로 한 줄로 분리
- 파일 검증 통과
- 대본 약 1,500음절: 보통 속도 약 4분 50초, 천천히 약 5분 25초
