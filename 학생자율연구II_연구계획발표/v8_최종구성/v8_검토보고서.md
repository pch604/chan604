## 2. 관점별 검토와 수정

### 제어 교수님
| 발견한 점 | 조치 |
|---|---|
| 5번: "(Lucas and Kanade, 1981)"이 EKF 문장 끝에 붙어 EKF 출처처럼 읽힘 | KLT 바로 뒤로 옮김: "KLT Optical Flow(특징점 추적, Lucas and Kanade, 1981)" |
| 6번: "타임스탬프는 실제 촬영 시점"은 카메라에만 해당 | "카메라 타임스탬프는 실제 촬영 시점"으로 한정 |
| 3번: PX4를 "상용 비행제어기"로 표기했으나 PX4는 오픈소스 | "드론 비행제어기(PX4)"로 수정 |
| 지연 실험 설계가 타당한가 | 6번에 "도착 시점 = 촬영 시점 + 실측 처리시간 + 추가 지연"을 명시. 추가 지연 범위는 PX4가 허용하는 0~300 ms 안의 값 |
| 남은 질문 예상: 상태벡터 | 화면에는 넣지 않음(내용 변경 금지). 답변: "위치·속도·자세, 측정은 회전 보상한 영상 이동과 거리" |

### 학교 직원 (비전공)
| 발견한 점 | 조치 |
|---|---|
| "IMU"가 처음 나올 때 설명이 없음 | 2번 첫 항목에 "IMU(관성측정장치)" 표기 |
| 그림 없이 개념만 나열 | 2번에 실제 드론 센서 사진 추가. 카메라와 거리센서가 무엇인지 눈으로 보임 |
| EKF·KLT 같은 약어 | 5번에 "EKF(확장 칼만필터)", "KLT(특징점 추적)" 병기 |

### 학부생
| 발견한 점 | 조치 |

## 3. 대본 흐름 점검

- 각 슬라이드 대본이 다음 슬라이드로 이어집니다.
  - 배경 → "풀어야 할 문제가 있습니다"
  - 필요성 → 목적
  - 선행연구 → "적용 전후 비교"
  - 방법 → 구현 → 일정
- 그림·표가 있는 슬라이드에서는 "(오른쪽 위 사진)", "(오른쪽 표)", "(아래 그림)"처럼 가리킬 곳을 대본에 적었습니다.
- 분량은 약 1,300음절입니다. 보통 속도로 약 4분 10초, 천천히 말하면 약 4분 40초라서 5분 안에 여유가 있습니다.

## 4. 남은 확인 사항

1. INSANE 실내 시퀀스 이름과 OptiTrack 구간은 데이터를 받은 뒤 확인하세요.
2. 3번 표의 IMU 200 Hz는 INSANE의 여러 IMU 중 200 Hz급 기준입니다. 실제로 쓸 IMU를 정하면 값을 맞추세요.
3. MS PGothic에는 한글 글자가 없어 PowerPoint가 대체 글꼴로 표시합니다. 발표용 PC에서 줄바꿈을 확인하세요.
4. 2번의 PX4 사진은 CC BY 4.0이라 출처 표기가 필수입니다. 슬라이드 하단과 노트에 적어 두었으니 지우지 마세요.
