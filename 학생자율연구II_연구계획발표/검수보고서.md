## 4. 하단 배너 처리

- **원본 개체를 그대로 이식했습니다.** 기존 v5 PPT의 슬라이드 마스터에서 배너 개체 4개의 XML과 원본 이미지(`image1.png` 부산대 로고, `image2.png` VDEC 로고)를 그대로 가져와 새 PPT의 슬라이드 마스터에 넣었습니다.
  - 캡처하거나 다시 그리지 않았습니다.
  - 로고의 색 투명 처리(clrChange)와 잘라내기(srcRect)도 원본 그대로입니다.
- **16:9에 맞춘 조정은 두 가지뿐입니다.**
  - 그라데이션 띠의 폭을 9,144,000 → 12,192,000 EMU로 늘렸습니다.
  - 오른쪽 부산대 로고는 오른쪽 끝과의 거리를 원본과 같게 유지했습니다.
  - 높이, y 위치(6.906 in), 로고 크기, 텍스트는 원본과 같습니다.
- **모든 슬라이드에 들어갑니다.** 배너는 마스터에 있으므로 표지를 포함한 전 슬라이드에 동일하게 표시됩니다. 쪽 번호는 배너 가운데에 있습니다(표지와 Q&A 제외).

### 5.2 그대로 두었고 검증된 내용

- **90 m 예시:** δp = ½·b·t² = ½ × 0.05 × 60² = 90 m로 계산이 맞습니다. "일정 바이어스·초기 오차 0 가정의 이론값, 실험 결과 아님"을 표기했습니다.
- **R의 역할:** K = PHᵀ(HPHᵀ + R)⁻¹이므로 R이 커지면 K가 작아지고, 측정 반영이 줄어듭니다(표준 EKF).
- **PX4 EKF2의 품질 기반 잡음 조절** — PX4-Autopilot 공개 소스(main 브랜치)를 직접 내려받아 확인했습니다. 근거는 `src/modules/ekf2/EKF/aid_sources/optical_flow/optical_flow_fusion.cpp`, `optical_flow_control.cpp`, `params_optical_flow.yaml`입니다.
  - `calcOptFlowMeasVar()`는 품질이 EKF2_OF_QMIN~최대일 때 잡음 표준편차를 `EKF2_OF_N_MAX`→`EKF2_OF_N_MIN`으로 선형 보간한 뒤 제곱합니다.
  - 품질이 `EKF2_OF_QMIN` 미만이면 측정을 사용하지 않습니다.
  - 관측값은 자이로로 보상한 flow rate(`flow_compensated = flow_rate − gyro`)입니다.
  - 예측값 `predictFlow()`는 기체 속도와 레버암 속도(ω × r)를 기체 좌표로 바꾼 뒤 `cos(tilt)/HAGL`(= 1/광축 거리)을 곱합니다.
  - 기울기 조건(`R_to_earth(2,2) > range_cos_max_tilt`)이 있습니다.
  - 슬라이드 6과 A2·A3의 식은 이 구조와 일치합니다.
- **광류 모델(A2 ①):** 표준 핀홀 카메라의 영상 Jacobian(interaction matrix)에서 영상 중심(x = y = 0)을 대입한 결과입니다. ẋ = −v_x/Z − ω_y, ẏ = −v_y/Z + ω_x. 부호는 축 정의에 따라 달라진다고 명시했습니다.

### 5.3 적응형 기법의 표현

- **새 기법이 아니라고 일관되게 표현했습니다.** 슬라이드 4·5·8과 대본 전체에서 "새 기법이 아닌 기존 기법의 적용·비교"로 썼습니다.
- **선행 사례를 명시했습니다.**
  - 측정 잡음 적응: Mehra (1970)
  - 품질 기반 flow 잡음: PX4 EKF2

## 8. 남은 확인 사항과 한계

1. **글꼴(중요).** 검수 환경에는 `맑은 고딕`이 없어 같은 계열의 Noto Sans CJK KR로 대체해 렌더링했습니다. PDF도 이 대체 글꼴로 만들어졌습니다.
   - LibreOffice는 한글과 영문 사이에 간격을 더 넣으므로, 실제 PowerPoint에서는 글자 폭이 조금 더 여유 있게 보일 가능성이 큽니다.
   - 발표 전 PowerPoint에서 한 번 넘겨 보며 줄바꿈 위치를 확인하세요. 특히 슬라이드 4·6·A2를 봐 주세요.
2. **PDF.** 최종 배포용 PDF가 필요하면 PowerPoint의 "PDF로 저장"으로 다시 내보내는 것을 권장합니다. 맑은 고딕이 반영됩니다.
3. **INSANE 세부 사양.** 영상 해상도·프레임률, LRF 주기, 외부 파라미터, 시퀀스별 정답 구간은 공개 요약만으로 확인했습니다. A4에 적은 대로 10월 초 실제 파일로 확인해야 합니다.
4. **IMU 바이어스 상태.** 포함 여부는 미결정 항목으로 남겼습니다(A3).
5. **특징점 추적 수치.** 기존 자료값입니다. 그림 재현이 필요하면 원본 스크립트로 다시 생성하세요.
6. **소스 재생성.** `source/make.sh`는 원본 v5 PPT(배너 원본)와 pptxgenjs가 필요합니다. 경로는 작업 환경 기준이라 다시 쓰려면 수정해야 합니다.
