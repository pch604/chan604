# v11 — 교수님 강의자료의 시각화 방식 반영

## 참고한 강의자료 표현 (AI Lecture 10~13, 안창선 교수님)
| 강의자료에서 쓰인 방식 | 예시 슬라이드 | v11 적용 |
|---|---|---|
| `time` 화살표 위에 같은 종류의 데이터를 둥근 상자로 나열 | RNN "Sequence Data" | 3번 시간축 그림 |
| 두 경우를 나란히 놓고 비교 | RNN "DNN for Sequence Data" (한순간 입력 vs 누적 입력) | 4번 A/B/C 비교 |
| 핵심 문장·부분에 **빨간 상자 + 빨간 라벨** | RL "강화학습" 정의, CNN "Q: What is the problem?" | 4번 C, 5번 늦은 측정 처리, 6번 가설, 7번 11월 |
| 문구 위·그림 아래, 또는 문구 왼쪽·그림 오른쪽 | RL "MDP" | 3·4·5번 |

## 슬라이드별 변경
- **3번 필요성:** Qin & Shen (2018) Fig. 1 방식의 시간축 그림을 넣었습니다.
  - 4줄 구성: IMU(200 Hz, 촘촘한 눈금) / 카메라 촬영(20 Hz) / 카메라 도착(빨강, d만큼 늦음) / 거리센서(30 Hz).
  - 빨간 상자와 문구로 "도착한 영상 = d만큼 이전의 움직임"을 표시했습니다.
  - 그림 형식의 출처를 그림 아래에 적었습니다.
- **4번 선행연구:** 문구를 두 줄로 줄이고, A(지연 무시) / B(지연 시점 융합, PX4) / C(과거 상태 재추정, Kim & Ahn·MSF-EKF) 비교 그림을 넣었습니다.
  - 각 칸에 "촬영 → 도착(현재)" 시간축을 그리고, 언제 보정하는지를 점과 화살표로 표시했습니다.
  - C는 빨간 상자로 "본 연구의 핵심 구현"을 표시했습니다.
- **5번 방법:** 늦은 측정 처리 3단계를 빨간 상자로 묶고 "본 연구의 핵심" 라벨을 달았습니다.
- **6번 평가:** A/B/C 설명은 4번과 중복되어 한 줄로 줄였습니다. 가설은 빨간 상자로 강조했습니다.
- **7번 일정:** 11월 행을 빨간 상자로 표시하고 "핵심 단계" 라벨을 달았습니다.
- **대본:** "(아래 그림)", "(아래 빨간 상자)"처럼 가리킬 곳을 맞췄습니다. 4번은 A/B/C 그림 설명으로 바꿨습니다.

## 글꼴과 글자 크기 점검
- 모든 슬라이드의 모든 글자를 스크립트로 확인했습니다. 영문은 Arial, 한글은 MS PGothic이며 예외는 0건입니다. 제목은 마스터의 Arial을 상속하고, 한글 글꼴은 MS PGothic으로 직접 지정했습니다.
- 글자 크기를 5단계로 통일했습니다 (본문 슬라이드 2~7).

| 용도 | 크기 |
|---|---|
| 소제목 | 17 pt |
| 섹션 제목 | 15.5 pt |
| 본문 | 14 pt |
| 그림·표 글자 | 12 pt |
| 캡션·출처 | 10.5 pt |

- 남은 확인 사항: MS PGothic에는 한글 글자가 없어 PowerPoint가 대체 글꼴로 표시합니다. 발표용 PC에서 줄바꿈을 한 번 확인하세요.
